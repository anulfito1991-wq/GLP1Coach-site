# GLP1Coach-site

Privacy policy and support page for [GLP-1 Coach: Shots & Plateaus](https://apps.apple.com/us/app/id6773481001) — an iOS app for tracking GLP-1 medications (Ozempic, Mounjaro, Wegovy, Zepbound, Rybelsus, etc.) with an on-device Apple Intelligence coach.
